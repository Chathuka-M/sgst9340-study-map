# SGST 9340 Study Map

Interactive study notes for **SGST 9340 Energy Storage & Power Electronics** (BCIT), Lectures 1–7.

Open the site: see the GitHub Pages link in this repository's About section.

## What's inside
- A searchable, collapsible mind map of Lectures 1–7, with key equations.
- Interactive explorers:
  - **L2** loss and junction temperature
  - **L3** duty cycle vs switching frequency; buck/boost conversion ratio
  - **L4** sinusoidal PWM: modulation index, carrier ratio, bipolar vs unipolar, filtered output
  - **L5–6** LLC gain curve (FHA) with a time-domain simulation of one switching period, plus an animated current-flow view
  - **L7** battery pack builder with a CC/CV charge profile

Lecture slides and slide figures are not included.

## Run locally
Download the repository and open `index.html` in a browser. No build step.
